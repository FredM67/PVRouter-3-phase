Detailed Description

Integer arithmetic of the energy bucket.

Author
Frédéric Metrich (frede.nosp@m.ric..nosp@m.metri.nosp@m.ch@l.nosp@m.ive.f.nosp@m.r)
Version
0.1

Copyright

The energy bucket used to be a float, which put libgcc floating-point calls in the ADC ISR. It is now an int32_t in fixed-point units: 1 unit = 1 / 2^FRACTION_BITS W x mains cycle.

The power calibration values stay floats in calibration.h. They are turned into 16-bit fixed-point constants at compile time, with a shift chosen so that the largest of them fills the 16 bits - the quantisation error then stays far below the accuracy of the calibration itself.

Note
This header has no Arduino dependency, so it can be exercised by the native test suite.
