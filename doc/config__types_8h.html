Detailed Description

What config.h is written with: its types, constants and helpers.

Author

config.h includes this file and nothing else. Nothing here depends on a setting, so config.h reads on its own, top to bottom, for the compiler as for the configurator. Nothing here depends on Arduino either: the native tests build it on the PC.

The settings types (RelayEngine, OverridePins, ScheduledBoosts, RotationGroups, TemperatureSensing) only hold what config.h says. The objects the firmware works with are built from them in config_derived.h, which the code includes instead of config.h.
