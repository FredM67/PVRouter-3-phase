Detailed Description

Encoding of the load map: one packed byte per dump load.

Author
Frédéric Metrich (frede.nosp@m.ric..nosp@m.metri.nosp@m.ch@l.nosp@m.ive.f.nosp@m.r)
Version
1.0
Date
2026-09-23
Copyright
Copyright (c) 2025-2026

Each entry of physicalLoadPin[] describes one dump load:

  • bits 6-7 : owning unit. 0 = local (driven by the router itself), 1..3 = remote unit number, reached over RF.
  • bits 0-5 : physical pin. For a local load this is the TRIAC pin. For a remote load this is an optional status LED pin on the router, 0 meaning "no LED".

Loads may be declared in any order; nothing assumes locals come first.

Note
This header is deliberately free of any Arduino dependency (its whole include closure is <stdint.h>) so the encoding and the census helpers can be exercised by the native test suite.
