Detailed Description

The forced outputs: the override pins, and the scheduled boosts of the dual tariff.

Author

Once per second, the firmware computes what is forced ON: the targets of each override pin held LOW, and the targets of each scheduled boost whose window is open. The functions here take every input explicitly (the pin states, the time elapsed since the start of the off-peak period, the temperature, the tables); main.cpp reads millis(), the pins and the globals, and calls them.

Note
This header has no Arduino dependency, so it can be exercised by the native test suite (test/native/test_override_masks).
