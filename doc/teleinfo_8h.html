Detailed Description

The telemetry frame of the IoT output, written a line at a time.

Author
your name (you@d.nosp@m.omai.nosp@m.n.com)
  • Frame Structure: a frame starts with a Start-of-Text (STX) character and ends with an End-of-Text (ETX) character. In between, one line per value: LF, tag (and index), TAB, value, TAB, checksum, CR.
  • Checksum: each line carries its own, (the sum of the bytes from the tag to the TAB before the checksum) & 0x3F, + 0x20.
  • Streamed: the frame is written one line per step of the serial output (see serial_output.h), as the text and JSON outputs: a line is built in a buffer of a few bytes on the stack, there is no frame buffer.
  • Arduino-free: the values come from a data source given as a template parameter (see writeFrameStep()), so the frame is tested natively (test/native/test_teleinfo).
  • Serial Configuration: Serial at 9600 baud, 7 data bits, even parity, 1 stop bit.
