Detailed Description

Performance benchmarks for FastDivision.

Measures execution time of AVR assembly fast division functions compared to standard C division operators.

Runs in CI in the simavr simulator (uno_sim environment): simavr is cycle-accurate, so the timings are exact and the same from run to run. On a connected board: pio test -e uno -f "*test_fastdivision_perf*"

Every result is also printed as a BENCH line (bench_report.h), for the CI benchmark history.
