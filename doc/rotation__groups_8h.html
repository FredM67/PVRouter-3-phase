Detailed Description

The rotation groups: which loads take turns, checked and resolved at compile time.

rotationGroups (config.h) lists, group by group, the loads that take turns at the top of the priority list: one group per appliance, such as the elements of a 3-phase water heater. The groups are written with target codes (config_types.h); this file turns them into load numbers, checks them for validation.h, and builds Rotation::Table: the priority places each group holds. Rotation only reorders the loads of a group among their places, so those places never change and are known at compile time.

No Arduino here: the native tests build it on the PC.
