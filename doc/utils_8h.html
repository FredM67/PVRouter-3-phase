◆ printCalibration()

template<bool newBoard>
void printCalibration ( const uint8_t phase)
inline

Print the calibration of a phase as calibration.h has it.

The new board: f_ctRating, f_powerCalPerAmp and f_voltageCalNewBoard; the old board: f_powerCalOldBoard and f_voltageCalOldBoard. The f_powerCal the router computes from them is not printed: what can be checked is what was typed. A template, so that each build compiles only its board's branch (its strings included).

Template Parameters
newBoardwhether the router runs with the new board's calibration
Parameters
phasethe phase, 0 for L1
