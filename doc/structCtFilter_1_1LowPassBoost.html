Detailed Description

The state of the filter of one CT (one per phase), and the filter itself.

The state is Robin's lpf_long (x256), kept as its x64 part and its 2 low bits: lpf_long = 4 x lpfX64 + lpfLowBits. Every multiply is then 16 x 16, and no shift of the state needs a loop.

Filters one sample.

As Robin's, at x256: lpf += alpha x (sample - lpf), truncated towards zero; then sample + gain x lpf, back to x64.

Parameters

coefficientsThe coefficients, from coefficientsOf(); a gain of 0 returns the sample.
Returns
The filtered sample, x64 scale, saturated to the int16 range.
