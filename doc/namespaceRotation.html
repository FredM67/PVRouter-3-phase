◆ loadsOf()

template<uint8_t NL>
uint32_t Rotation::loadsOf ( const uint8_t code,
const uint8_t(&) loadMap[NL] )
constexpr

The loads a target code stands for, by load number.

LOAD(n) is load n of the load map, LOCAL_LOAD(n) the same if it is local, REMOTE_LOAD(n) the n-th remote load in map order, a plain number the local load on that pin, ALL_LOCAL_LOADS(), ALL_REMOTE_LOADS() and ALL_LOADS() their loads.

Parameters
codea target code, as written in rotationGroups
loadMapthe load map (physicalLoadPin)
Returns
bit n set for each load n the code stands for; 0 if it stands for no load (a relay, a load number beyond the map, a pin with no local load on it)
