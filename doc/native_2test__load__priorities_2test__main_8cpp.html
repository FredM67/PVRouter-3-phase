Detailed Description

Native unit tests for load_priorities.h: the load priority state machine.

The priority array holds one logical load per element, the highest priority first: the physical load number in the low 7 bits, the ON state in the high bit. Once per mains cycle, Switching::onNewCycle() may switch one load, depending on the energy bucket; toPhysical() then gives the physical states. No config.h, no stubs: the real code, on a bucket of 1000 units.
