template<bool Normalise>
uint16_t Datalog::squareRoot ( uint32_t value,
uint8_t & fractionBits )
inline

Square root, rounded to the nearest integer, of the value or of the value normalised.

Digit by digit, two bits of the value per bit of the root, most significant first. The remainder (value - root^2 so far, < 2^19 before each trial) and twice the root (< 2^17) fit in 3 bytes; keeping twice the root makes each trial a single compare: remainder >= 2 x (2 x root) + 1 <=> remainder > 2 x (2 x root).

On AVR, this is assembly: the value is consumed a byte at a time, each bit of the root costs ~21 cycles, and the normalisation ~6 cycles per byte and ~12 per pair of bits (avr-gcc's code for the same needs about twice as much; see test_datalog_math_avr).

Template Parameters
Normalisefalse: round(sqrt(value)). true: the value is first shifted left by pairs of bits up to >= 2^30, so that the root has 15 to 16 significant bits.
Parameters
valueThe value to take the square root of.
[out]fractionBitsThe number of fractional bits of the result (0 if not normalised).
Returns
round(sqrt(value) x 2^fractionBits), at most 65535.

uint16_t Datalog::vrmsFactor ( const uint8_t datalogPeriodInSeconds)
constexpr

Scaling of the datalog voltage, Vrms_L_x100.

Hundredths of a volt. For datalog periods over 10 s, processVoltage() scales V^2 down by 16 so that the sum cannot overflow: the root is then 4 times smaller, hence x4.

Parameters
datalogPeriodInSecondsDATALOG_PERIOD_IN_SECONDS.
Returns
The factor for voltageCalibration(): 100, or 400 for periods over 10 s.
