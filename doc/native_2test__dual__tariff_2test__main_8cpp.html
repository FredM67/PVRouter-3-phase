Detailed Description

Native unit tests for utils_dualtariff.h: the scheduled boosts of the dual tariff.

Each boost has a window (FIRST, LAST, FROM_START/BEFORE_END with or without FOR, in HOURS() or MINUTES()) and its targets. The firmware resolves each window at compile time, in ms from the start of the off-peak period, and forces the targets while millis() - start is in it. No config.h, no stubs: the real code.
