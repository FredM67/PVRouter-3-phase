Detailed Description

Performance benchmarks for assembly multiplication functions.

Version
0.1
Date
2026-11-20

This file contains performance benchmarks for the assembly-optimized multiplication functions. They run in CI in the simavr simulator (uno_sim environment), which is cycle-accurate: the timings are exact and the same from run to run. Every result is also printed as a BENCH line (bench_report.h).

Based on:

  • florentbr's optimization suggestions for PVRouter
  • avrfreertos multiplication optimizations by feilipu
  • OpenMusicLabs AVR assembly techniques
