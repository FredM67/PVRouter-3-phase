Detailed Description

Performance benchmarks for assembly multiplication functions.

Version
0.1
Date
2026-11-13

This file contains performance benchmarks for the assembly-optimized multiplication functions. These tests should only be run on real hardware, not in CI simulators where timing is meaningless.

Based on:

  • florentbr's optimization suggestions for PVRouter
  • avrfreertos multiplication optimizations by feilipu
  • OpenMusicLabs AVR assembly techniques
