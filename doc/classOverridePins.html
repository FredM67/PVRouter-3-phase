Detailed Description

template<uint8_t N, uint8_t MaxPins = 16>
class OverridePins< N, MaxPins >

The override pins, as in config.h: each pin with the targets it forces.

The targets stay codes here; OverrideTable (utils_override.h) holds what they force.

Template Parameters
NNumber of override pins.
MaxPinsMaximum number of targets per pin.
