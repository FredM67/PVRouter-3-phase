Detailed Description

Native unit tests for relay_engine.h: the decisions of the relay diversion.

The real code, no stubs: RelayLogic::Relay on an output that records each switch (pin, new state) instead of driving a pin, and RelayLogic::Engine on those relays. As in loop(), the engine gets inc_duration() then proceed_relays() once per second. The average is negative on a surplus, positive on an import.

Each relay pin differs from its index, so that a test tells an override bit read by index from one read by pin.
