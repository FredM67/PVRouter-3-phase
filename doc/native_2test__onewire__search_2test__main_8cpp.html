Detailed Description

The ROM search of onewire_search.h, on a simulated 1-Wire bus.

The simulated bus is wired-AND, as the real one: a device sends a 0 by pulling the line low, so the master reads 1 only if every device in the search sends 1. After each bit and its complement, the master writes the branch it takes: the devices with the other bit leave the search until the next reset.
