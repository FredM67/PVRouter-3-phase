Detailed Description

template<uint8_t N, uint8_t MaxPins = 16>
class BoostSchedule< N, MaxPins >

The scheduled boosts: a window and the bitmasks of its targets, for each entry.

Same accessors as OverrideTable, so that a target check takes either. Built from the ScheduledBoosts of config.h and a TargetMap (utils_override.h), or from plain pins.

Template Parameters
Nnumber of boosts
MaxPinsmaximum number of pins (loads + relays) of a target list
