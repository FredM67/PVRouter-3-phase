The Dallas/Maxim CRC-8 (x^8 + x^5 + x^4 + 1), as OneWire::crc8.

Bit by bit, as the OneWire library without its table (ONEWIRE_CRC8_TABLE 0): its 32-byte table is not worth it for one scratchpad a second. The firmware's own copy, so the native tests check the CRC the firmware runs.

Parameters
dataThe bytes
lenTheir number
Returns
The CRC: the 9th byte of a scratchpad, the 8th of a ROM code

◆ skipPowerOnValue()

int16_t DS18B20::skipPowerOnValue ( int16_t reading,
int16_t previous )
constexpr

The reading to keep, the power-on value skipped.

A sensor that has just been powered (plugged, or a power glitch) answers 85.00 °C before its first conversion. 85.00 °C more than 5.00 °C away from the previous reading is that value, not a temperature.

Parameters
readingThe reading of the sensor
previousThe last valid reading (PowerOnFilter keeps it)
Returns
reading, or DEVICE_DISCONNECTED_RAW for the power-on value

◆ toHundredths()

int16_t DS18B20::toHundredths ( uint8_t lsb,
uint8_t msb )
constexpr

The temperature of the register, in hundredths of °C.

The register is the temperature x16 (1/16 °C at 12 bits), two's complement. x6.25 = x6 + x/4, rounded down (towards -infinity): 1/16 °C gives 6, -1/16 °C -7.

Parameters
lsbByte 0 of the scratchpad
msbByte 1 of the scratchpad
