Detailed Description

Unit grouping and payload bookkeeping for remotely controlled loads.

Author
Frédéric Metrich (frede.nosp@m.ric..nosp@m.metri.nosp@m.ch@l.nosp@m.ive.f.nosp@m.r)
Version
1.0
Date
2026-09-23
Copyright
Copyright (c) 2025-2026

Given the load map (see load_map.h) and the current state of every dump load, this builds one RF payload per remote unit and decides when a transmission is due. It knows nothing about the radio itself: the actual send lives in remote_loads.h, outside the ISR.

Each unit is sent one byte, one bit per load: **bit b of a unit's payload is the b-th load of that unit in ascending physicalLoadPin[] order.** The receiver must agree.

A payload is transmitted when it changes, and otherwise refreshed every REMOTE_REFRESH_CYCLES mains cycles so a receiver that missed a packet - or was powered up late - converges within 100 ms.

Note
This header has no Arduino dependency (its whole include closure is <stdint.h> and load_map.h) so it can be exercised by the native test suite.
