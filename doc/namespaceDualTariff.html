uint32_t DualTariff::windowStart ( const BoostWindow & window,
const uint8_t offPeakHours )
constexpr

The start of the boost window, in ms from the start of the off-peak period.

A start before the period wraps around to a very large value: the window then never opens. validation.h rejects such a window at compile time, with startsWithinOffPeak().

Parameters
offPeakHoursthe duration of the off-peak period, in hours (12 at most)
