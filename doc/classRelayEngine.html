Detailed Description

template<uint8_t N, uint8_t D = 10>
class RelayEngine< N, D >

The relays, as in config.h: the sliding average and the settings of each relay.

RelayDiverter (utils_relay.h) is the engine built from them.

Template Parameters
NNumber of relays.
DDuration of the sliding average, in minutes (RELAY_FILTER_DELAY).
