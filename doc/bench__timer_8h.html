Detailed Description

Exact CPU cycle count of a benchmark loop, whatever its length.

Timer1 counts every CPU cycle; its overflow interrupt extends it to 32 bits, so a loop of up to 268 s can be timed. During the measurement, the millis() interrupt of Timer0 is paused and pending serial output has been sent: the only interrupt left is the Timer1 overflow, which happens a fixed number of times for a given loop. The count is then exact and the same from run to run, wherever the loop starts - unlike micros(), which advances in steps of 4 us and includes every millis() interrupt in between.

The cycles of start() and stop() themselves are measured once and subtracted.

BenchTimer::start();
for (...) { ... }
