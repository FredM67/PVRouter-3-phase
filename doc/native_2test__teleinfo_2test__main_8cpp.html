Detailed Description

Native tests for teleinfo.h: the IoT frame, streamed a line per step.

The frame is written by TeleInfo::writeFrameStep(), one line per step of the serial output (STX before the first line, ETX after the last), from a data source: here, test sources with feature sets of the firmware. It must give, byte for byte, what the buffered TeleInfo class of the firmware wrote before (Reference below, its code kept as it was, utoa() replaced by snprintf()), with N and V sent unsigned.
