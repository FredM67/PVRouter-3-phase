RFM69 & SharedRF::radio ( )
inline

Accessor for the shared RFM69 instance.

Returns
Reference to the one and only RFM69 object

The radio is a function-local static rather than a namespace-scope object on purpose. A namespace-scope RFM69 would have a dynamic initializer, which is emitted into .init_array whether or not any RF feature is enabled, and that reference alone drags the whole RFM69 driver (~2.9 kB of flash) into every build. As a function-local static it is only created if this function is actually called, so with RF_CHIP_PRESENT == false the linker drops it.
