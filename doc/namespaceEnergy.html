Check that the calibration values can be represented.

Every value must be positive, and the largest must leave enough fractional bits for contribution(): shift >= FRACTION_BITS + 9, i.e. values below ~8.

◆ toHundredthsOfJoule()

template<uint8_t SUPPLY_FREQUENCY>
int32_t Energy::toHundredthsOfJoule ( const int32_t units)
constexpr

An energy in bucket units, in hundredths of a joule (for the datalog).

units * 100 / (SUPPLY_FREQUENCY * 2^FRACTION_BITS), with the fraction reduced at compile time (1/8 at 50 Hz, 5/48 at 60 Hz) so that it cannot overflow, rounded half away from zero as Print::print(float) did. No float code.

Template Parameters
SUPPLY_FREQUENCYmains frequency in Hz
