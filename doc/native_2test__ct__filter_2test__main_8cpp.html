Detailed Description

Native tests for ct_filter.h: the CT low-pass filter, in fixed point.

The current sample reaches the filter DC-removed, left-aligned (x64 scale, int16). The reference is Robin's filter (Mk2_fasterControl_Full), verbatim, in float at his x256 resolution: the fixed-point filter must track it within TOLERANCE of its output on a step, a sine and noise, for the settings of the old boards (alpha 0.0011, gain 9), the shipped alpha (0.002) and a few gains.
