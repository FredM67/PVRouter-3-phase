Detailed Description

Native tests for adc_chain.h: the six conversions, the reference and the ADMUX pipeline.

The ADC converts six channels in a fixed chain V1, I1, V2, I2, V3, I3. It runs free: when the ISR of a finished conversion runs, the next conversion has already started with the previous ADMUX, so the ADMUX written now applies to the conversion after next. The pipeline test plays this out and checks that the channel really converted is the one the ISR believes it handles, on each board. The last test pins the values of the table that processing.cpp wrote by hand before it was built from adc_chain.h.
