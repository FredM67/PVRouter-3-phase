Detailed Description

The checks of a DS18B20 reading (ds18b20.h): CRC, conversion, range, power-on value.

The scratchpads are those of a DS18B20: temperature LSB and MSB, TH = 0x4B, TL = 0x46, configuration 0x7F (12 bits), 0xFF, 0x0C, 0x10, then the CRC. The CRC of a few of them is checked against known values first, so the other tests can build theirs with crc8().
