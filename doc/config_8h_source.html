68// ----------- Pinout Assignments -----------
69//
70// ANALOG pins:

73// DIGITAL pins:
74// - D0 & D1: Reserved for the Serial interface.

76// RFM69 module (RF data logging or remote loads):

78// - D10: Chip Select (CS).

93// Rotation groups: the loads that take turns at the top of the priority list, when
94// PRIORITY_ROTATION is not OFF. One group per appliance, e.g. the 3 elements of a water heater:
95// { { ALL_LOCAL_LOADS() } } - one heater, every local load
96// { { LOAD(0), LOAD(1), LOAD(2) }, { LOAD(3), LOAD(4), LOAD(5) } } - two heaters
97// Each group rotates among the priority places its loads hold; loads in no group never move.

109//--------------------------------------------------------------------------------------------------
110// EWMA Filter Tuning for Cloud Immunity
111//
112// The RELAY_FILTER_DELAY parameter controls how aggressively the EWMA filter smooths
113// power measurements before making relay decisions. This directly affects cloud immunity vs responsiveness.
114//
115// 🌤️ Quick Reference by Climate:
116// - Clear sky regions (desert, dry): 1 minute (fast response, minimal clouds)
117// - Mixed conditions (most locations): 2 minutes (recommended default)
118// - Frequently cloudy (coastal): 3 minutes (enhanced stability)
119// - Very cloudy (mountain, tropical): 4 minutes (maximum stability)
120//
121// 📖 Full guide: docs/Cloud_Pattern_Tuning_Guide.md, at the root of the repository
122//--------------------------------------------------------------------------------------------------
123inline constexpr uint8_t RELAY_FILTER_DELAY{ 2 };
