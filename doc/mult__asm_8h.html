Detailed Description

Assembly-optimized multiplication functions for AVR microcontrollers.

Author
Based on florentbr's suggestions and avrfreertos optimizations
Version
0.1
Date
2026-09-23
Copyright
Copyright (c) 2025-2026

This file contains highly optimized assembly multiplication functions for time-critical operations on AVR microcontrollers. These functions eliminate the overhead of GCC's library calls for 16/32-bit multiplications.

Based on:

  • florentbr's optimization suggestions for PVRouter
  • avrfreertos multiplication optimizations by feilipu
  • OpenMusicLabs AVR assembly techniques
