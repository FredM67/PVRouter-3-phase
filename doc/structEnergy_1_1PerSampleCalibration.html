Detailed Description

template<uint8_t NMin, uint8_t NMax, uint8_t N>
struct Energy::PerSampleCalibration< NMin, NMax, N >

cal / n for every phase and every expected sample count n, in fixed point.

One cycle's contribution is (sumP / n) x cal = sumP x (cal / n). With this table the ISR multiplies sumP directly, with no division - and without the truncation of that division either.

Template Parameters
NMinSmallest expected number of sample sets per mains cycle.
NMaxLargest expected number of sample sets per mains cycle (<= 64, so that sumP stays within the 24 bits contribution() expects).
NNumber of phases.
