Detailed Description

template<typename R, uint8_t N, uint8_t D>
class RelayLogic::Engine< R, N, D >

A collection of relays, switched one at a time from a sliding average.

Template Parameters
RThe relay type: a Relay<>, or a type derived from one.
NThe number of relays to be managed.
DThe duration in minutes for the sliding average.
  • Relay Management: Handles the state of multiple relays, turning them ON or OFF based on surplus and import thresholds.
  • Sliding Average: Uses an Exponentially Weighted Moving Average (EWMA) to calculate the average power over a configurable duration.
  • State Transitions: Ensures stable operation by enforcing minimum ON/OFF durations and a delay between state changes.

void RelayLogic::Engine< R, N, D >::proceed_relays ( const uint16_t overrideBitmask,
const bool diversionEnabled = true ) const
inline

Proceed all relays: OFF in decreasing order, ON in increasing order.

Parameters
overrideBitmaskOverride bitmask (local pins): a relay is forced ON while its bit is set
diversionEnabledWhether diversion is enabled - if false, only the forced relays are ON

This method adjusts the state of the relays based on the current average power. If surplus power is available, it tries to turn ON relays in increasing order. If power is being imported, it tries to turn OFF relays in decreasing order. On a surplus too, a relay in battery mode (negative import threshold) that goes OFF does so in decreasing order, before any relay comes in. When diversion is disabled, the relays that are not forced are turned OFF. The minimum ON and OFF times, and the settle time after any change, always apply.
