Detailed Description

Native unit tests for pin_edges.h.

The edges of the active-LOW input pins: pinEdges(), trackPinEdges<pin>() and isRotationRequested(). Each pin keeps its previous level in a static of its own trackPinEdges<pin>(), for the whole run: each test uses pins of its own, so that it starts from the startup state (released).
