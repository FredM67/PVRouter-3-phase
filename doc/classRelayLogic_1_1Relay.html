Detailed Description

template<typename Output = NoOutput>
class RelayLogic::Relay< Output >

The state of one relay, and its decisions.

  • Relay Control: The relay is turned ON when the surplus threshold is exceeded and turned OFF when the import threshold is crossed.
  • Time Constraints: Minimum ON and OFF durations ensure stable operation.
  • State Management: The class tracks the relay's current state and the duration of its current state.

On each change, Output::switched(pin, on) drives the pin (relayOutput, utils_relay.h); then the state changes, and the methods return true.

Template Parameters
OutputA type with a static switched(uint8_t pin, bool on), called on each change.
