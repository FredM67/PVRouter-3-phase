Detailed Description

Native unit tests for energy_bucket.h.

The integer energy bucket must reproduce the float arithmetic it replaces, bucket += (l_sumP / n) * f_powerCal[phase] over the full input range, without overflow and without drifting over time. The float/double expression is the reference. No config.h, no stubs.
