Detailed Description

Native unit tests for datalog_math.h.

The integer datalog arithmetic must reproduce the float arithmetic it replaces (#120), power_L = -(sumP / n) * f_powerCal[phase] Vrms_L_x100 = factor * f_voltageCal[phase] * sqrt(sum_Vsquared / n) over the full input range, without overflow. The float expressions, evaluated in double precision, are the reference. No config.h, no stubs.

template<uint8_t N>
static double worstVrmsError ( uint16_t factor,
const float(&) cal[N],
uint32_t maxMeanSquare )
static

Largest error of vrms() against the reference, from 0 to the largest ADC voltage, beyond what the 16-bit square root and calibration constant explain.

Both have at least 16 significant bits (relative error <= 2^-16 each, 2^-14 with a margin), and the result is rounded (<= 0.5): the returned value must stay <= 0.5, i.e. 0.012 V at most at 230 V.

Largest error of watts() against the reference, over the full input range, beyond what the 16-bit calibration constant explains.

The calibration constant has at least 16 significant bits (relative error <= 2^-16, the same constant as in the ISR), and the result is rounded (<= 0.5 W): the returned value must stay <= 0.5 W.
