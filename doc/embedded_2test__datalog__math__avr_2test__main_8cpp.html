Detailed Description

The integer datalog arithmetic on the target: exact results, and cycle counts against the float code it replaces.

Version
0.1
Date
2026-11-13

datalog_math.h replaced, in the datalog (#120):

  • power_L = (int16_t)(sumP / n * f_powerCal[phase])
  • Vrms_L_x100 = (uint32_t)(100 * f_voltageCal[phase] * sqrt(sum_Vsquared / n)) The assembly square root is checked at every rounding boundary of the 32-bit range, and the integer version must not be slower. Timer1 runs at the CPU clock (prescaler 1) with interrupts disabled, so the counts are exact CPU cycles, in simavr as on a real board. The overhead of the measurement itself is subtracted.

◆ test_isqrt_on_avr_every_boundary()

void test_isqrt_on_avr_every_boundary ( void )

Every rounding boundary of every root, on the target: the assembly loop is exact.

round(sqrt(x)) changes from r to r + 1 between r^2 + r and r^2 + r + 1, since (r + 0.5)^2 = r^2 + r + 0.25. Checking r^2 - 1 (from r = 2), r^2, r^2 + r and r^2 + r + 1 for all 65536 roots covers every boundary of the 32-bit range (up to 65535^2 + 65535 = UINT32_MAX), and with them the largest remainders (worst cases of the 3-byte remainder) and the carries of each byte.
