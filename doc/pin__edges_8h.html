Detailed Description

The edges of the active-LOW input pins: pressed, released, or no change.

Author
Frédéric Metrich (frede.nosp@m.ric..nosp@m.metri.nosp@m.ch@l.nosp@m.ive.f.nosp@m.r)
Version

The diversion, router OFF, dual tariff and rotation pins are read once per second. Each one keeps its previous level, released at startup: the new level and the previous one give its edges.

Note
This header has no Arduino dependency, so it can be exercised by the native test suite. The pin itself is read in main.cpp (readPinEdges()).
