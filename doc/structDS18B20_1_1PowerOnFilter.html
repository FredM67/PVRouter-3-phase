Detailed Description

The readings of one sensor, the power-on value skipped.

Compares each 85.00 °C with the last valid reading: an invalid reading in between (a CRC error) leaves it as it was. Compared with the reading kept last time, a steady 85.00 °C would be dropped for good after a single CRC error. At startup, the reference is 0, so a first reading of 85.00 °C is skipped.
