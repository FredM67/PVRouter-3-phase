Detailed Description

template<uint8_t N, uint8_t D = 10>
class RelayDiverter< N, D >

Manages a collection of relays and their behavior based on surplus and import thresholds.

The decisions are those of RelayLogic::Engine (relay_engine.h), on relays that drive their pins (relayOutput). Here, the constructors, which check the sliding average duration, and the printing of the configuration. config_derived.h builds it from the RelayEngine of config.h.

Template Parameters
NThe number of relays to be managed.
DThe duration in minutes for the sliding average (default is 10 minutes).
