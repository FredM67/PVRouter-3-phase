Detailed Description

Native unit tests for override_masks.h: what is forced ON, by the override pins and the scheduled boosts of the dual tariff.

The pins and boosts are built with the real OverrideTable and BoostSchedule, and the boosts resolved with DualTariff::resolve(), as dualtariff.h does at compile time. A pin is active when LOW: here, when its bit is set in a mask of active pins.
