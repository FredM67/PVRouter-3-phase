Detailed Description

Machine-readable lines per benchmark result, for the CI performance report.

Prints BENCH|<name>|<value>|<unit> on its own line. CI collects these lines from the verbose output of the embedded tests (scripts/ci/bench_to_json.py), measures the target branch of a pull request in the same run, and posts the comparison as a comment (scripts/ci/pr_report.py); each push to dev adds them to the history on GitHub Pages (scripts/ci/pages_update.py). Smaller is better. simavr is cycle-accurate, so the values are exact and the same from run to run.

The name must stay the same over time: it is the key of the comparison.

void benchCycles ( const __FlashStringHelper * name,
const uint32_t cycles,
const uint32_t ops = 1 )
inline

A result in CPU cycles, reported twice: in microseconds and in cycles.

<name> [us] is cycles / 16 at 16 MHz, with four decimals (exact for a single call: 1/16 = 0.0625). <name> [cycles] is the count itself, with two decimals for a loop. Measured with BenchTimer (bench_timer.h), or with Timer1 directly.

Parameters
namethe name, saying what one operation is for a loop ("... per op")
cyclesthe cycles of the whole loop
opsthe operations in the loop, to report one of them: 1 for a single call
