Detailed Description

The codes LOAD(), RELAY() and ALL_...() put in a target list.

Which pin load #1 is, and which relays exist, is only known once config.h is read: the helpers cannot give a pin here. They give a code, and config_derived.h turns each code into its pin(s) (TargetMap, in utils_override.h). A plain number in a list is a pin, and so is REMOTE_LOAD() (from REMOTE_PIN_BASE on).
