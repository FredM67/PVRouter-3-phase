Detailed Description

Integer arithmetic of the datalog: power and RMS voltage per phase.

Author
Frédéric Metrich (frede.nosp@m.ric..nosp@m.metri.nosp@m.ch@l.nosp@m.ive.f.nosp@m.r)

At the end of each datalog period, the main loop turns the sums of the ISR into watts and volts. This used to be float arithmetic (a multiplication by f_powerCal, sqrt() and a multiplication by f_voltageCal), which linked about 750 bytes of libgcc/libm float code and kept the calibration arrays in RAM (#120).

The calibration values stay floats in calibration.h. They are turned into 16-bit fixed-point constants at compile time (Energy::toFixed()), and the square root is an integer one, computed on a normalised value so that it keeps 15 to 16 significant bits.

Note
This header has no Arduino dependency, so it can be exercised by the native test suite.
