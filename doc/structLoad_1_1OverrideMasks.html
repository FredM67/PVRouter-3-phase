Detailed Description

template<uint8_t N>
struct Load::OverrideMasks< N >

Override bit of each load, in the local or in the remote override bitmask.

Built at compile time, so that the ISR tests a load's override with a mask instead of shifting by its pin (a loop on AVR) or counting its remote ordinal.
