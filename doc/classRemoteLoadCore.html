Detailed Description

template<uint8_t NumUnits>
class RemoteLoadCore< NumUnits >

Builds and schedules the RF payloads of every remote unit.

Template Parameters
NumUnitsNumber of remote units, 0 to MAX_REMOTE_UNITS.

The load map is a template argument of updateLoads() rather than read from the physicalLoadPin[] global: the tests pass maps of their own, and the compiler resolves every load's unit and payload bit, so the ISR only tests states and ORs bits.

The default constructor is constexpr and every member carries a brace-or-equal initialiser, so an instance at namespace scope is constant-initialized: it lands in .bss with no .init_array entry, and is dropped altogether by --gc-sections when unused.

Claim a pending transmission for one unit.

Clears the pending flag, so a second call returns false until the state changes again or the refresh period elapses. Safe to call from loop() without disabling interrupts: flag and payload are single bytes, and if the ISR updates them in between, the newer payload is sent and the flag stays set, so at worst the same byte goes out twice.

Parameters
unitIdxZero-based unit index (unit number - 1).
payloadReceives the bitmask to transmit.
Returns
true if a transmission is due.

template<uint8_t NumUnits>
template<const auto & Map, uint8_t NumLoads>
void RemoteLoadCore< NumUnits >::updateLoads ( const LoadStates(&) loadStates[NumLoads])
inline

Rebuild every unit's payload from the current load states.

Called once per mains cycle, from the ADC ISR. Local entries of the map are skipped, as is any entry naming a unit beyond NumUnits.

The map is a template argument, so the unit and the payload bit of every load are resolved at compile time: what is left at run time is, per remote load, one state test and one OR into a register.

Template Parameters
MapThe packed load map; must have static storage (a namespace-scope or static constexpr array).
Parameters
loadStatesThe current state of each load, in the same index space.
