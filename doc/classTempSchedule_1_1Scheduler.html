Detailed Description

template<uint8_t N, uint16_t CONVERSION_CYCLES>
class TempSchedule::Scheduler< N, CONVERSION_CYCLES >

The round of the sensors, one transaction per mains cycle.

Main-loop code. The state is two small counters, the sensor and its transaction, advanced by compare and reset: no division at run time (the divisions above are compile-time only).

Template Parameters
NThe number of sensors
CONVERSION_CYCLESconversionCycles(SUPPLY_FREQUENCY)

bool TempSchedule::Scheduler< N, CONVERSION_CYCLES >::newPeriod ( )
inline

A datalog period begins: a new round, once this one is over.

An unfinished round (only after many late cycles) goes on: the sensors it has not read yet keep the values of the period before.

Returns
true if a new round starts: its conversion can run at once, in the cycle that ends the period (which had no transaction, the round being over)
