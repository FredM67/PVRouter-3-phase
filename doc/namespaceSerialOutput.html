A float constant as an integer with the given number of decimals, rounded.

For compile time only (constexpr variables): Print::print(float) costs about 1 kB of float code, printDecimals() only integer divisions. toDecimals(0.05F, 6) -> 50000, printed by printDecimals(out, 50000, 6) as "0.050000".
