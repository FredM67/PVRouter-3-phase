Detailed Description

template<uint8_t N, uint8_t MaxPins = 16>
class OverrideTable< N, MaxPins >

Manages override pins and their associated bitmasks for forced operation.

This class provides compile-time mapping between override pins and the loads/relays they control. Each pin can be associated with a set of pins (loads/relays), represented as separate bitmasks for local loads/relays and remote loads.

Template Parameters
NNumber of pin-index pairs (entries).
MaxPinsMaximum number of pins supported (loads + relays). Default is 16.
